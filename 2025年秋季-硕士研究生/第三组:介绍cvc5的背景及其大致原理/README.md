## 项目简介

本目录包含 CVC5 SMT（可满足性模理论）求解器的 Python 演示代码，作为《数学逻辑》课程的实践教学材料。

**CVC5** 是一个高效的自动定理证明器，支持多种逻辑理论，包括：
- 命题逻辑
- 一阶逻辑
- 算术理论
- 位向量理论
- 数组理论
- 字符串理论

## 思考与应用

CVC5 将抽象的数学逻辑理论转化为可执行的程序验证工具，通过约束求解实现：

程序正确性验证

硬件电路设计验证

人工智能推理系统

数学定理自动证明
